記錄並分享日常音樂練習的應用程式

1. 概要

即使拿著樂器，也能輕點一下記錄練習時間，並在上課時展示給老師看的iPhone App。透過記錄和分享兩個畫面，將日常練習帶入課堂交流。

負責問題定義、UX/UI設計、實機調整、實作和資料製作。實作過程與AI協作，並由我自行判斷是否採用畫面和操作方案。

我在自己的練習和課程中使用了這款應用程式。老師表示內容一目了然，也提出希望記錄得更細緻的需求（大意）。

透過 Web 示範進行操作

2. 背景與問題

我以業餘身分練習次中音薩克斯風，每兩週上一次課。老師問我「最近練得怎麼樣？」時，我卻沒有辦法具體說明練了什麼、練了多久。

薩克斯風掛在背帶上，練習時很難騰出手在紙上寫字。日誌的頁數一多，記錄也會散落難找。

我試過時間記錄 App，雖然可以一鍵計時，但如何把記錄整理成老師一眼就能看懂的形式，仍是個問題。

3. 設計方針

讓練習時的記錄和上課時的分享銜接成一個完整流程。為此，我把兩項要求作為決定畫面和操作方式的標準。

練習時，盡量減少輸入

拿著樂器也能透過輕點分類卡片記錄時間。

展示給老師前，盡量減少編輯

記錄能自動彙整，可以直接展示練了什麼、練了多久。

4. 功能與設計

將操作和練習時間放在同一張卡片上

輕點類別卡片即可開始計時；輕點另一張卡片可切換；再次輕點同一張卡片則停止計時。卡片上醒目顯示今日練習時間，只有計時過程中才會高亮並加上白色外框。操作的位置和確認記錄內容的位置保持一致。

無需橫向捲動即可查看練習明細

為了免去分享前的編輯，應用程式會自動彙整上次上課日以來的記錄。每日表格優先採用能同時顯示所有類別的配置，即使文字需要縮小也如此。目標是讓使用者能一邊向老師展示畫面，一邊聊練習時間的分配。

讓累積的練習成為堅持下去的動力

把今日完成情況以及按月、按年累積的練習視覺化。我希望老師能看到自己付出的努力，這也能成為持續練習的動力。

每日｜以1小時為目標，讓進度條填滿

今日練習進度條最初以1小時為上限顯示。我把各類別的練習時間用不同顏色疊加，希望嘗試達到這個目標能成為開始練習的契機。

長期｜用綠色方格呈現日積月累

每天用一個方格表示，並以綠色深淺表示當天的練習時間。設計上希望能一覽按月、按年累積的方格，並讓日常記錄逐漸增加的樣子成為堅持練習的契機。

5. 製作過程

透過調查和交流，明確記錄與分享各自的作用

我使用 ChatGPT 調查了現有 App，並整理問題和解決方向。在當時的調查範圍內，我找到了時間管理 App，但沒有找到適合與老師溝通的分享機制。我透過對話逐步明確概念，整理成規格說明，再交給 Codex 讀取並實作初版。

試用初版，將操作區域收進畫面內

我親自試用了生成的初版，提出 UI 和 UX 改進需求，並據此調整出改良版。初版中分開的計時狀態資訊和結束操作被整合進卡片，今日時長也改為醒目顯示。我還嘗試調整配置，讓操作面板能完整顯示在畫面內。

練習時需要一直開啟這個畫面，因此以黑色為主色，同時希望類別色彩能帶來明快的感覺。

親自比較操作手感，再決定採用哪種方案

僅靠文字或圖片難以準確描述「順暢滑動、穩穩停住」的手感。因此，我與AI一起製作了一個輔助工具，可以自行更改方案和參數來測試。我以操作面板能停在畫面範圍內為標準，在實機上比較後，選擇了瀏覽器原生的吸附捲動，並應用到程式中。

透過獨立評審輔助檢查，由我決定是否採用

我用兩個獨立的AI工作階段反覆進行這個流程：先自行檢查 Claude Code 提出的問題和改進建議，再由 Codex 驗證並落實必要的修正。建議有時會偏離預期的 UI 或 UX，因此我會結合應用程式的目的和實際手感決定是否採用。
＊這個流程重複了約15次；當AI評審不再提出重大缺陷時，我將其作為結束改進的一個參考標準。

6. 使用結果與後續計畫

練習開始時開啟應用程式已成為習慣

我把應用程式安裝在自己的 iPhone 上，在日常練習中使用，確認了拿著樂器也能輕點一下記錄的便利性。練習開始時開啟應用程式逐漸成為正向的習慣；回顧當天的練習順序與分配、留意下次上課日，也有助於規劃自己的練習。

老師提出希望記錄得更細緻

老師表示練習內容一目了然，也認為如果能記錄具體音階類型會更有幫助（大意）。這些回饋來自我自己的練習和與老師上課時的實際體驗。

接下來的課題是兼顧記錄細節與輸入便利

我正在考慮在「音階」下設定「五聲音階」等子類別。如何讓記錄操作依然簡單，還在持續探討。對於分享畫面，也在考慮用類別和子類別的階層顯示取代每日表格。
