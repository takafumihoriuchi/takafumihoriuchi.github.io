概述

在平台鋼琴的內部，按下琴鍵的動作經由多重連桿逐級傳遞，最終使琴槌向上彈起，轉化為琴弦的振動。這套讓琴鍵被按下時能夠帶動琴槌擊弦的槓桿系統，稱為「擊弦機」。本專題在SolidWorks*上把這套擊弦機重建為3D模型，並以運動分析考察琴鍵上的輸入如何轉化為琴槌的速度與琴弦的反作用力。

分析之前，先依據參考圖片從零開始對琴鍵機構進行3D建模，再以這個模型執行了兩項運動分析：一項是下沉的琴鍵與彈起的琴槌之間的速度關係，另一項是施加於琴鍵的力與作用到琴弦的力之間的關係。3D模型上得到的模擬數值，與依尺寸和支點位置推算出的理論值相互對照，藉此確認運動與力在模型內部是如何傳遞的。

* SolidWorks：3D CAD系統。在設計階段即可進行考察零件強度的結構分析，以及確認運動狀況的運動分析。

把擊弦機做成可供分析的3D模型

把一次觸鍵變成一次擊弦的機構

擊弦機是把琴鍵的向下運動轉換為琴槌向上運動的機構。按下琴鍵後，頂桿螺絲、連動桿、擊弦機頂桿、複振槓桿等隨之連動，琴槌被抬起並擊打琴弦。演奏者看到的只是一次觸鍵，而在其內部，多個零件分別繞著不同的支點轉動，在彼此接觸之中把運動傳遞下去。

3D建模涵蓋了琴鍵、琴槌、頂桿、連動桿、複振槓桿、頂桿螺絲、制音器、制音槓桿、金屬線，以及支撐它們的框架。要理解其運動，僅僅端詳成品的形狀並不足夠，還必須界定哪個零件以何處為支點轉動、又觸及下一個零件的哪個部位。

從剖面圖做出3D模型

本專題並未採用現成的CAD資料，而是以擊弦機的剖面資料為底圖描摹各零件的輪廓，逐一建立3D模型。隨後把零件組成組合件，並設定與實際機構相對應的固定關係與轉動關係。這道工序把一個供人觀看形狀的模型，轉變為一個可以施力、可以運動的分析模型。

以自由度確認拘束條件

扣除固定的框架，可動零件共9個，若無拘束則合計具有54個自由度。把頂桿螺絲與金屬線固定於其他零件，可減少12個自由度；再以轉動接頭拘束其餘7個零件，又減少35個。因此，此CAD組合件的自由度為7，如下所示。

54 − 12 − 35 = 7

SolidWorks的拘束診斷同樣顯示，估計自由度與實際自由度皆為7，冗餘拘束為0。這並非斷定實物擊弦機整體自由度的數值，而是確認本專題所設定的零件構成與拘束條件確實依預期組裝完成。

兩項分析——琴鍵輸入如何被轉換

模型的行為分為兩項分析來考察。分析1是「琴鍵移動的快慢如何轉換為琴槌的快慢」，分析2是「施加於琴鍵的力如何以琴弦一側的反作用力呈現」。每次只擷取一組輸入與輸出，便能把複雜連桿機構的行為，化為可用幾何速度比與槓桿力平衡來說明的形式。

比較的基準，是把機構置換為簡單轉動構件之後的理論計算。理論值與模擬值若相接近，至少可以判斷模型內部的運動，符合由所設定的尺寸與拘束條件所應期待的關係。

分析1——琴鍵的速度在琴槌處被放大了多少

在速度分析中，把複雜的擊弦機簡化為琴鍵、以連動桿為中心的中間機構、琴槌這三個在接觸中傳遞運動的剛體。把運動理解為依序從圖中的①傳到③，由眾多零件構成的機構便可當作三級轉動來計算。

同一剛體上角速度相同，若以r表示至支點的距離、以v表示該點的線速度，則v = ωr。若假定接觸點處速度無損耗地傳向下一個剛體，把各級的輸入半徑與輸出半徑之比相乘，即可求得琴槌速度。

vhammer = (r1′ r2′ r3′ / r1 r2 r3) vkey

輸入條件與觀測結果

在SolidWorks Motion Analysis中，於琴鍵末端向下施加5 N，觀測琴鍵末端與琴槌的線速度。開始施力後不久出現的尖峰速度，琴鍵為1,027 mm/s，琴槌為4,284 mm/s。也就是說，在模擬中琴槌的速度約為琴鍵的4.17倍。

觀測·計算對象速度
琴鍵（模擬）1,027 mm/s
琴槌（理論計算）4,614 mm/s
琴槌（模擬）4,284 mm/s

與理論值的比較

自模型上量得的半徑為r1 = 200 mm、r1′ = 88 mm、r2 = 53 mm、r2′ = 78 mm、r3 = 16 mm、r3′ = 111 mm。代入公式之後，理想化的速度比約為4.49倍，據此可預測：對應1,027 mm/s的琴鍵速度，琴槌速度應為4,614 mm/s。

模擬值4,284 mm/s雖比理論值低約7%，但速度被放大的幅度相當接近。產生這項差異的原因，如後文所述，在於把機構理想化為三個剛體的理論計算，與連零件間損耗和材料變形一併處理的3D模擬，兩者前提不同。

分析2——琴鍵上的力在琴弦一側如何呈現

第二項分析在琴鍵表面向下施加15 N，觀測擊弦時出現於琴弦一側的反作用力。琴鍵一側的輸入Fkey自1.0秒起上升至15 N，而在擊弦的瞬間，琴弦一側的反作用力Vstring出現了最大31 N的尖峰。

這項數值可由琴鍵一側與琴槌一側的力臂長度所構成的槓桿平衡來說明。

Vstring = (15 × 195) / 94 = 31.1 N

取輸入點至支點的距離為195 mm、至琴弦一側作用點的距離為94 mm來計算，理論值為31.1 N。與模擬最大值31 N相差0.1 N；在這項分析中，結果同樣與由所設定尺寸所應期待的力的傳遞幾乎一致。

模擬結果與理論值的對照

兩項分析都得到了相近的結果

在比較琴鍵與琴槌速度的分析1中，相對於琴槌速度的理論值4,614 mm/s，3D模擬的結果為4,284 mm/s。在比較琴鍵輸入與琴弦反作用力的分析2中，相對於理論值31.1 N，模擬的最大值為31 N。兩項分析中，所建3D模型的模擬結果都與由公式求得的理論值相接近。

產生細微差異的原因

理論計算把擊弦機簡化為由三個剛體構成的機構，並以接觸點處運動與力無損耗傳遞為前提來計算。而3D模型的模擬須處理構成擊弦機的每一個零件，因此零件之間的能量損耗與材料變形也會反映在結果之中。正是這項前提上的差別，表現為理論值與模擬值之間的細微差異。

結論

可以確認，3D模擬的結果與理論值幾乎相等。依剖面圖建立的3D模型，以與理論計算相符的方式再現了擊弦機的運動——把琴鍵的輸入放大為琴槌的速度，並把這份力傳向琴弦。

在這個專題中所做的，不只是複現形狀。從剖面資料中讀出結構、把零件之間的關係轉譯為CAD中的拘束、再依所要分析的問題把它簡化為力學模型，這些都作為同一個建模過程被貫通起來。
