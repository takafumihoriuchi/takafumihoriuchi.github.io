概要

グランドピアノの内部では、鍵盤を押す動きが複数のリンク機構を介して連鎖的に伝わり、最終的にハンマーが跳ね上がり、弦の振動に変換される。この鍵盤が押された時にハンマーを動かして弦を打てるようにしているテコのシステムを「ピアノ・アクション」と呼ぶ。このプロジェクトでは、このピアノ・アクションをSolidWorks（※）上に3Dモデルとして再構成し、鍵盤への入力がハンマーの速度と弦の反力へどのように変換されるかをモーション解析した。

解析にあたり、参考画像をもとにピアノ鍵盤の機構を一から3Dモデリングし、そのモデルを使用して二つの運動解析を実施した。一つは押下される鍵盤と跳ね上がるハンマーの速度の関係、もう一つは鍵盤に加える力と弦に加わる力の関係である。3Dモデルで実施したシミュレーションの値を、寸法と支点位置の計算から導いた理論値と照合し、モデルの中で運動と力がどのように伝達されるかを確かめた。

※ SolidWorks：3D CADシステム。設計段階で、部品の強度を調べる構造解析や動きを確認するモーション解析ができる。

ピアノ・アクションを、解析できる3Dモデルへ

一打鍵を、打弦へ変える機構

ピアノ・アクションは、鍵盤の下向きの動きをハンマーの上向きの運動へ変える機構である。鍵盤を押すと、キャプスタン、ウィペン、ジャック、レペティションレバーなどが連動し、ハンマーが持ち上がって弦を打つ。演奏者から見える動作は一つの打鍵だが、その内側では複数の部品が異なる支点のまわりを回転し、互いに接触しながら動きを受け渡している。

3Dモデリングにおいては、鍵盤、ハンマー、ジャック、ウィペン、レペティションレバー、キャプスタン、ダンパー、ダンパーレバー、ワイヤーと、それらを支えるフレームを含めた。運動を理解するには、完成形を眺めるだけでなく、どの部品がどこを支点に動き、次の部品のどこへ触れるかを定義する必要があった。

断面図から3Dモデルをつくる

既製のCADデータを使うのではなく、ピアノ・アクションの断面資料を下絵にして各部品の輪郭をトレースし、一点ずつ3Dモデルを作成した。次に部品をアセンブリとして組み、実際の機構に対応する固定関係と回転関係を設定した。この工程によって、形を見るためのモデルを、力を加えて動かせる解析モデルへ変えた。

拘束条件を、自由度として確認する

固定したフレームを除く可動部品は9点で、拘束がなければ合計54自由度を持つ。キャプスタンとワイヤーを別の部品へ固定すると12自由度が減り、残る7部品を回転ジョイントで拘束すると、さらに35自由度が減る。したがって、このCADアセンブリの自由度は次のように7となる。

54 − 12 − 35 = 7

SolidWorksの拘束診断でも、推定自由度と実自由度はいずれも7、冗長拘束は0と表示された。これは実物のピアノ・アクション全般の自由度を断定する値ではなく、このプロジェクトで設定した部品構成と拘束条件が意図どおり組まれていることの確認である。

二つの解析——鍵盤入力がどう変換されるか

モデルの挙動は、二つの解析に分けて調べた。解析1は「鍵盤の動く速さが、ハンマーの速さへどう変換されるか」、解析2は「鍵盤へ加えた力が、弦側の反力としてどう現れるか」である。入力と出力を一組ずつ切り出すことで、複雑なリンク機構の挙動を、幾何学的な速度比と、てこの力のつり合いから説明できる形にした。

比較の基準には、機構を単純な回転要素へ置き換えた理論計算を用いた。理論値とシミュレーション値が近ければ、少なくともモデル内部の運動が、設定した寸法と拘束から期待される関係に沿っていると判断できる。

解析1——鍵盤の速度は、ハンマーでどれだけ増幅されるか

速度の解析では、複雑なピアノ・アクションを、鍵盤、ウィペンを中心とする中間機構、ハンマーという三つの剛体が接触しながら動きを伝えるモデルへ単純化した。図中の①から③へ運動が順に受け渡されると捉えることで、多数の部品からなる機構を三段の回転運動として計算できる。

同じ剛体上では角速度が共通であり、支点からの距離をr、その点の線速度をvとすると、v = ωrとなる。接触点で速度が損失なく次の剛体へ伝わると仮定すれば、各段の入力半径と出力半径の比を掛け合わせて、ハンマー速度を求められる。

vhammer = (r1′ r2′ r3′ / r1 r2 r3) vkey

入力条件と観測結果

SolidWorks Motion Analysisで鍵盤端へ下向きに5 Nを加え、鍵盤端とハンマーの線速度を観測した。力を加え始めた直後のピーク速度は、鍵盤が1,027 mm/s、ハンマーが4,284 mm/sだった。シミュレーション上では、ハンマーが鍵盤の約4.17倍の速さで動いたことになる。

解析1のピーク速度
観測・計算対象速度
鍵盤（シミュレーション）1,027 mm/s
ハンマー（理論計算）4,614 mm/s
ハンマー（シミュレーション）4,284 mm/s

理論値との比較

モデルから測った半径は、r1 = 200 mm、r1′ = 88 mm、r2 = 53 mm、r2′ = 78 mm、r3 = 16 mm、r3′ = 111 mmである。これらを式へ代入すると、理想化した速度比は約4.49倍となり、鍵盤速度1,027 mm/sに対するハンマー速度は4,614 mm/sと予測される。

シミュレーション値4,284 mm/sは理論値より約7%低いものの、速度が増幅される大きさは近い値となった。この差が生じた理由は、後述するように、三つの剛体として理想化した理論計算と、部品間の損失や材料の変形まで扱う3Dシミュレーションとで前提が異なるためである。

解析2——鍵盤の力は、弦側でどのように現れるか

二つ目の解析では、鍵盤表面へ下向きに15 Nを加え、打弦時に弦側へ現れる反力を観測した。鍵盤側の入力Fkeyは1.0秒から立ち上がって15 Nに達し、打弦の瞬間、弦側の反力Vstringには最大31 Nのピークが現れた。

この値は、鍵盤側とハンマー側の腕の長さを使った、てこのつり合いから説明できる。

Vstring = (15 × 195) / 94 = 31.1 N

入力点から支点までの距離を195 mm、弦側の作用点までを94 mmとして計算すると、理論値は31.1 Nになる。シミュレーションの最大値31 Nとの差は0.1 Nであり、この解析でも、設定した寸法から期待される力の伝達とほぼ一致した。

シミュレーションと理論値の照合

近い値となった二つの解析結果

鍵盤とハンマーの速度を比較した解析1では、ハンマー速度の理論値4,614 mm/sに対して、3Dシミュレーションでは4,284 mm/sとなった。鍵盤の入力と弦の反力を比較した解析2では、理論値31.1 Nに対して、シミュレーションの最大値は31 Nだった。どちらの解析でも、作成した3Dモデルによるシミュレーション結果は、数式から求めた理論値と近い値になった。

わずかな差が生じた理由

理論計算では、ピアノ・アクションを三つの剛体からなる機構として単純化し、接触点で運動や力が損失なく伝わるものとして計算した。一方、3Dモデルによるシミュレーションでは、ピアノ・アクションを構成する一つひとつの部品を扱うため、部品間で生じるエネルギーの損失や材料の変形も結果に反映される。この前提の違いが、理論値とシミュレーション値の間に生じたわずかな差として現れた。

結論

3Dシミュレーションの結果が理論値とほぼ等しいことを確認できた。断面図をもとに構築した3Dモデルは、鍵盤の入力をハンマーの速度へ増幅し、その力を弦へ伝えるピアノ・アクションの運動を、理論計算と整合する形で再現した。

このプロジェクトでは、形状を再現するだけでなく、断面資料から構造を読み取り、部品同士の関係をCAD上の拘束へ置き換え、解析する問いに応じて力学モデルへ単純化するまでを一つのモデリング過程として行った。
