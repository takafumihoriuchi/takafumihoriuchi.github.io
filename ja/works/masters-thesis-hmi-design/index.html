人とロボットのインタラクション設計に関する修士論文

著者：堀内 貴文（Takafumi Horiuchi）

  • LinkedIn
  • GitHub

2021年7月

概要

大きなロボットを操作する人は、作業空間の一部にしか一度に注意を向けられない。その注意がいまどこにあるかを機械に伝えたら何が変わるか——この研究はそう問うた。操作者の視線がロボットの振る舞いを決める衝突回避システムを設計した。操作者の中心視野に入っているものは自由に扱え、そこから外れたものは保護される——アームは減速し、届く前に止まる。事前に何かをラベル付けする必要はない。区別は作業のその瞬間に、操作者がたまたま見ている場所から引かれる。デモ映像はこちら（YouTube）。

ミラノ工科大学 Design & Engineering の修士論文として、日本の株式会社人機一体での研究インターンシップ中に取り組み、第39回日本ロボット学会学術講演会（RSJ2021）で発表した。

いまの私のデザイン哲学が現在の形をとりはじめたのも、ここだった。このシステムが読んでいるのは命令ではなく認知の状態——そもそもそれが目に入っているかどうか——であり、その状態を、機械が動いてよい条件へと変換している。デザインの対象はロボットの動きではなく関係のほうだ。機械が何をしてよいかは、人がいま何を把握しているかから決まる。個々の振る舞いではなくその関係をデザインするというやり方は、動く側がロボットアームではなく生成AIになったいま、私がしていることと同じ動作である。

要旨

人間操作ロボットが価値を持つのは、まさに自律ロボットが力を発揮できない場所である。目の前の作業のために設計されたわけではない空間、ぶつけてはならない人や設備のとなり。既存の衝突回避システムはそうした空間に、あらゆる対象を「操作の対象」か「保護すべきもの」かとしてあらかじめ宣言させることで対応してきた。現場から現場へ運ばれる機械にとって、この初期設定の負担は現実的な水準を超える。

この研究は、その区別を事前ではなく実行時に、操作者の視線から与えることを提案した。操作者の中心視野の内側にある対象は操作可能、外側にあるものは保護対象、人はいかなる場合も保護対象として扱う。この手法は、それまで受動的なセンサ情報だけで組まれてきた制御ループに、能動的なパラメータ——人間由来のパラメータ——を持ち込む。プロトタイプは身長1.9mの人型重機ロボット JINKI type Zero に実装し、5回のデモ試行を通じて定義どおりに動作した。

1. はじめに

人間操作ロボットは、同時に得ることの難しい二つのものを併せ持つ。機械の出力と精度、そして人の状況判断である。完全自律のロボットは後者をまだ提供しない。また、産業用ロボットが柵の内側の設計されたセルで働くのに対し、人間操作ロボットは別の目的のために整えられた場所——現場作業者のかたわら、繊細な設備のあいだ、原子力施設や建設現場——で働くことが期待される。周囲のものを壊さないと保証できることは、したがってこの機械が使えるかどうかの一部である。

偶発的な接触に対する確立された備えは二つある。マニピュレータの重要部位すべてを近接センサで覆う感覚皮膚と、周囲を点群として再構成し仮想空間で距離を計算する深度センシングである。どちらも機能する。しかしどちらも、ロボットの周りの対象が触れてよいものと触れてはならないものにすでに仕分けられていることを前提とする。その仕分けがなければ、何にもぶつかってはならない機械は何も操作できない。現場から現場へ運ばれ、そこにあるものの中に据えられる汎用の道具にとって、この設定と較正の手間は、それが買う安全よりも高くつく。

この研究が通り抜ける入口は、人間操作ロボットにはもともと制御ループの中に人がいる、という点にある。操作ミスの研究は、状況認識——自分の周りで何が起きているかを正確に掴んでいること——を決定的な要因として挙げており、状況認識は視線の方向と強く相関することが知られている。衝突回避はこれまで受動的な情報、すなわちセンサから読み取ったデータだけで組まれてきた。そこに能動的なパラメータをひとつ、操作者がどこを見ているかを加えると、ある対象への接触が意図されたものかどうかの手がかりがシステムに与えられる。

2. システムの振る舞い

操作者が触れる意図を持っている対象を操作可能な対象と呼び、制限なく扱える。操作者がそうした意図を持たない対象は保護対象であり、触れることはできない。ある対象がその瞬間どちらであるかは、操作者の中心視野に対する位置から決まる。内側にあれば、その対象は意図されたものとみなせるだけの操作者の認識のもとにあり、外側にあればそうではない。

そこから導かれる振る舞いを、五つの規則が定める。マニピュレータは中心視野の内側にある対象とは自由に干渉してよい。外側にある対象とは干渉できず、近づくにつれて徐々に停止する。停止した状態からは、操作者の視野がそこへ移るにつれて徐々に解除される。すでに接触している対象から視野が外れた場合には制限をかけない——進行中の作業が、ほかへ目をやっただけで中断されないためである。そして人に対しては、その人がどこに立っていても干渉できない。マニピュレータが複数ある場合、規則はそれぞれに個別に適用される。

これによって操作者は、自分が見ているものに対しては全速で作業しながら、見ていない設備には機械がぶつからないと信頼できる。現場の人の安全は無条件であり、操作者の意図にはまったく依存しない。

3. 期待される効果

この種の作業に最も近い既存の光景は重機である。大きな力が、人のとなりの整備されていない場所で加えられる。衝突事故は世界中の建設現場で主要な危険のひとつであり、不注意はその原因として繰り返し挙げられてきた。2018年に欧州の建設現場で記録された362,600件の事故のうち19.6%が動いている物体との接触によるものであり、クレーン関連の事故を調べた研究はそのうち19%を操作者の不注意に帰している。

注意と視線の方向は強く相関するため、この二つの割合を掛け合わせれば、視線を用いるシステムが覆いうる範囲のおおまかな見積もりが得られる——欧州で年あたり一万三千件程度である。この数字は公表統計からの推論であって測定結果ではなく、規模感を示すものとして挙げている。

4. システムの検証

概念実証として、デモンストレーション用のシステムを構築し動作させた。

4.1 実装

システムは、株式会社人機一体で開発されたロボット JINKI type Zero に実装した。人の上半身の形を持ち、身長1.9m、重量600kg、30自由度を備える。操作者とロボットは同じ場所にいて、master-slave 方式で結ばれる。VRヘッドセットが操作者の視界と頭部の回転をロボットのそれと同期させ、機械を運転しているというより機械と一体になっている感覚を与える。

ロボットに載せたLIDARが周囲の作業場を点群としてスキャンし、点群は仮想空間でそれぞれコライダーを持つボクセルとして表現される。同じ空間の中をロボットのデジタルツインが動き、そのアームがボクセルと重なると、システムは近接警告を出す。警告の効き方は操作者の視野の向きによって変わる。視野は60°×55°（水平×垂直）の錐体としてモデル化してある——人が記号・色・奥行きを知覚できる領域に近い値である——その向きはヘッドセットの正面方向で近似する。警告は実機へ送られ、前節の規則に従って動きを形づくる。

4.2 デモンストレーション実験

実装が定義どおりに動くかを、予備評価で確かめた。操作者に求めたのは、脇を見たままアームをポールへ向けて動かし、システムが警告を出してアームを停止させたことを確認し、停止したアームに視線を向けて制限を解除し、最後にポールの上のボールを視野に入れたまま掴むことである。試行は5回で、1〜3回目と5回目は熟練した操作者が、4回目は搭乗2回目の操作者が行った。いずれも録画した。5回とも、システムは第2節の定義どおりに振る舞った。デモの様子は動作中のシステムの映像で見られる。

5. 限界と今後の課題

人の検出はプロトタイプには実装しなかった。検証が必要だったのは操作者の視線と対象の操作可能性との関係であり、人を守る規則は無条件でそれに依存しないためである。この検出を加えればシステムはより頑健になり、安全の枠を超えた応用も開ける——たとえば操作者の視界でロボットの近くにいる人を強調する、あるいは近接警告が働く前に知らせる、といったことである。

視線はヘッドセットの正面方向で近似した。master-slave 方式で重要になる直接性を買って選んだ方法だが、据え置きのカメラやスマートグラスの視線計測など、別の機器なら別の推定の仕方があり、装着に慣れていない産業へこうしたシステムを持ち込むときの心理的な障壁を下げられるかもしれない。移動するロボットへ適用する場合にはもうひとつ問題が生じる。JINKI type Zero は開発段階にあるため据え置きだが、動作中に位置を変える機械には、それに追いつけるだけの効率的な点群処理が要る。

評価そのものは定性的なままである。このシステムを正しく評価するには実地での定量調査が筋であり、それはロボットが実用段階に達するのを待つことになる。

6. 結論

この研究は、人と設備への意図しない接触を防ぐために操作者の視線を用いる、人間操作ロボットのマニピュレータ向け衝突回避システムを提案した。認識と視線の方向が強く相関するという前提のもと、操作者の中心視野の内側にある対象を操作可能、外側にあるものを保護対象として扱った。人間の要素を制御ループに組み込んだことで、既存の手法が求める準備を一切必要とせず、その線を実行時に引けるようになった。

システムは汎用の重機ロボット上で検証し、定義どおりに動作した。同じ原理は、機械を動かすループにもともと人が入っているあらゆる場面へ持ち込めるはずである。

謝辞

本研究は、ミラノ工科大学 Design & Engineering の修士課程の一部として、株式会社人機一体でのインターンシップ期間中に行われた。この機会を実現してくださった両組織に深く感謝する。
