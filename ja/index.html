自主プロジェクト

  • Personal Fit UI - 制約型デザインによるUIの個別最適化（2026年8月） 認知・感覚・身体特性に合わせたUIを、科学的根拠と設計上の制約の内側で生成する。その可能性と限界をカーナビで検証した。
  • 世界で自分だけのポケモンの生成（2026年7月） ゲームの途中で、プレイヤーの言葉から新種を生成し、出会い・捕獲までを一つの体験にした。AIに何を作らせるかではなく、何を守らせるかを設計した研究プロトタイプ。

過去の学術研究

  • 人とロボットのインタラクション・デザインに関する修士論文（2021年7月） 操作者が「見ているか」を、ロボットが動いてよい条件へ変換する。人の認知状態を安全制御に組み込み、事前の対象登録なしで衝突を防ぐ仕組みを提案・実装した。
  • 制約型プログラミングに関する卒業論文（2019年6月） シミュレーション中、二度と成立しない条件を見極めて探索から外す。結果を変えずに計算量を減らし、評価モデルの実行時間を約半分にした。
  • Smart Codesign VR（2021年2月） SNaPボードゲームで子どもが考えたスマートオブジェクトを、VR空間で組み立てて動かす。環境・入力・出力の3枚のカードから、条件と振る舞いを自分の手で定義するプロトタイピング環境。
  • Design Studio (2019年–2020年) 修士課程のプロジェクト。記事は準備中。
  • ピアノ・アクションの運動解析（2020年1月） 断面図からピアノ・アクションを3Dモデル化し、鍵盤の入力がハンマーの速度と弦の反力へどう変わるかを、理論計算とSolidWorksの解析で確かめた。

今の「デザイン」についての私の考え

AIは、与えられた条件の中で多様なコンテンツを生成できる。しかし、何が生まれ得るのかを決めているのは、AIに与えたデザイン空間の方である。目的、価値、優先順位、制約、禁止事項、評価基準 — これらが境界を定め、AIはその内側を探索する。個々の成果物ではなく、この空間そのものを設計する（仮に「制約型デザイン」と呼ぶ）。同時に、制約は可能性を残すための設計であり、最後にどのような形で世に出すのかは、人が決めなければならない（いわゆる「審美眼」）。空間を設計し、そこから一つの形を選び切る。その両方を引き受けることが、AI活用時代のデザイナーの仕事だと考えている。
